# New Feature Prompt

## Objective
Design and implement a production-ready feature.

## Instructions
- Understand the business goal.
- Review existing architecture and coding standards.
- Produce a technical design.
- Implement with no placeholders or mock logic.
- Add tests, documentation, accessibility, performance, and security considerations.
- Update database migrations if required.
- Prepare a clean pull request and handoff.

## Deliverables
- Implementation plan
- Code changes
- Tests
- Documentation
- Release notes
